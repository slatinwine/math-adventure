# 数学世界奇遇记 · 正式入口

本项目是「数学世界奇遇记」的入口页：说书人「阿列夫」主持的对话式数学冒险（723 篇 OpenAI 数学手稿 · 五关一境）的正式版引导页，5 秒倒计时后自动跳转官方站点。

## ✨ 功能特性

- **自动跳转**：5 秒倒计时结束自动跳转正式版，也可点击「立即进入」直接前往
- **跳转进度条**：与倒计时同步的加载进度条，实时显示剩余秒数
- **数学符氛围动画**：ℵ、π、∞、∑ 等数学符号随机上浮旋转的背景动效
- **品牌化视觉**：宋体书卷风配色与呼吸发光的 ℵ 标识

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可看到入口页并自动跳转正式版（需要联网）。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript，零依赖、零构建、单文件
- `meta refresh` + JS 倒计时双保险跳转，CSS keyframes 动画
